## 🛠️ Tech Stack

- **HTML** (`index.html`)
- **CSS** (`style.css` - Pure Vanilla CSS Design System)
- **JS / React** (`src/App.jsx`)

---

## ⚡ Features & Options

- **Option A — Profile Frame** (Default First Option):
  - Branded profile avatar wrap frame with event dates and hashtag.
- **Option B — Builder ID Card**:
  - Event pass with Name, Stack / Role, and a generated Builder Title.
- **HEIC & Image Support**: JPG, PNG, WEBP, and iPhone HEIC photo decoding.
- **1-Click Share & Download**: PNG export and direct Share to X with mandatory `#FrameInGoa` hashtag.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Sahitya0805/Hacker-House.git
cd Hacker-House

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

# 🌴 HH Goa 2026 Frame & Builder ID Generator

An instant, mobile-first web application where builders and attendees of **HH Goa 2026** (28–31 October 2026, Goa, India) can upload their photos and generate branded social media graphics, identity cards, and profile avatar frames.

---

## 🛠️ Tech Stack

- **HTML5** & **CSS3**
- **JavaScript / TypeScript** & **React 18**
- **Vite** & **Tailwind CSS**
- **HTML5 Canvas API**
- **Lucide Icons**, **canvas-confetti**, **heic2any**

---

## ⚡ Core Options

- **Option A — Profile Frame**:
  - Turn your profile photo into an HH Goa 2026 branded avatar with circular wrap frame and event dates.
- **Option B — Builder ID Card**:
  - Official event builder pass featuring Name, Stack / Role, and a generated Builder Title.

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Sahitya0805/Hacker-House.git
cd Hacker-House

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
